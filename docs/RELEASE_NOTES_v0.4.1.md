## 2｜全域防溢出：平板上「孩子上過的課程」整頁跑版

根因不是 RWD 斷點，而是教案裡貼了一則 **743 字元、整串沒有 `/` 的 Yahoo 搜尋網址**。
瀏覽器找不到任何可斷行的位置，只能把那一行整串排出去，頁面被撐到 4931px 寬（平板視窗 820px），
Safari 為了塞得下就把整頁縮小。Chromium 實測一樣會溢出，不是 Safari 獨有的問題。

原本只有五個頁面各自寫了斷行設定，另外五頁沒有。改成 `style.css` 一段全域規則，三層：

| 層 | 規則 |
| --- | --- |
| 文字 | `body { overflow-wrap: break-word }`（會繼承，全站生效；只在單字本身超過一行寬時才斷） |
| 媒體 | `img, video, iframe, canvas, svg, embed, object { max-width: 100% }` |
| 保險 | `html, body { overflow-x: hidden }`（任何元素都不能把頁面撐寬） |

不用 `overflow-wrap: anywhere`（Safari 支援不完整）、不用 `word-break: break-all`（會切斷正常英文單字）。
需要橫捲的區塊（服事總覽表、日期列）各自有 `overflow-x: auto`，不受影響。

實測（測試帳號接正式資料，備課頁 → 幼童班 → 09/19 那筆）：

| | 修改前 | 修改後 |
| --- | --- | --- |
| 平板 820 | 4931 / 820 溢出 4111px | 820 / 820 |
| 手機 390 | 4931 / 390 溢出 4541px | 390 / 390 |

15 個頁面 × 兩種寬度全部無溢出；英文句子仍只在空白處換行、中文段落高度不變。
新增 `src/__tests__/style.test.ts` 把關三層規則。
