# 平台更新說明 v0.3.2（2026-09-04）

> v0.3.0 之後的更新：一項新功能（公告分類）＋一項修正（組織架構頁）。

## 新增：公告分成「行政」與「課程」兩類

家長常常分不出一則公告是**行政通知**（說明會、繳費、活動）還是**跟上課有關**（金句、要帶的東西）。
現在每則公告都會標明分類，也可以只看其中一類。

**家長／老師看到什麼**

- 每則公告卡片左上角多一個分類標籤：**🏛 行政**（橘）或 **📖 課程**（綠）
- 公告標題上方一排可點的按鈕：**全部 ／ 🏛 行政 ／ 📖 課程**，預設「全部」
  - 只想看跟上課有關的，點「課程」即可
  - 公告全都是同一類時，這排按鈕**不會出現**（不佔版面）
- 標籤改到標題上方獨立一行，標題不會再被擠到換行；班別標籤也改用班別顏色，和點名、出席紀錄一致

**同工發布時**

- 發布／編輯公告的「標籤」改成「**分類**」，選 🏛 行政 或 📖 課程（預設行政）
- 原本的「公告／重要」不再使用——**要強調的公告請用「置頂」**（📌），它同時決定排序與醒目度

**既有公告怎麼處理**

執行 migration 時會自動對應：原本標「重要」的（多為課堂提醒）→ **課程**，其餘 → **行政**。
對應完請同工到首頁看一遍，有不對的直接編輯改掉即可。

> 為什麼不做成上下分區或頁籤？公告目前約 1.5 則／月，一年也才十幾則，
> 分區會讓「最新的一則不一定在最上面」，頁籤則會預設藏起一半內容、
> 而且新公告若在沒選中的頁籤使用者不會發現。
> 篩選按鈕在量少時不礙事、量多時才發揮作用，是這個規模最合適的做法。

## 修正：組織架構頁看不到老師名單（手機）

**問題**：手機上打開「我的 → 組織架構與分工」，只看得到架構圖，
要往下滑很久才會出現老師名單——家長最想看的「孩子班上的老師」等於被藏起來了。

**原因**：架構圖本身不高（手機上約 190px），真正的問題是版面——
圖片區塊自帶了一層「整頁」容器（最小高度＝一個螢幕），
老師名單被整整一個螢幕的空白推到第一屏之外。

**修正**：

- 圖片區塊改為單純的「內容區塊」，外層頁面容器由頁面自己負責，不再重複套用。
- 組織架構頁的圖片另外限高（螢幕高度的 40%），
  並在圖下方加一行「🔍 點圖放大看細節」——之後若換上比較長的架構圖也不會再把名單擠掉。
- 異象頁不受影響（該頁下方沒有其他內容，圖維持原本大小）。

**結果**：架構圖與三個班的老師名單現在同時落在第一屏內。
