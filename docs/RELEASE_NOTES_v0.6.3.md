## 1. 聚會日可「單次改期」：12/5 園遊會 → 改到 12/6

- 新設定 `src/lib/config.ts` 的 `GATHERING_OVERRIDES`（原定日 → 實際日），**只改那一次**，其他週仍是週六。
- 目前設定：`'2026-12-05': '2026-12-06'`。
- 套用範圍：出席行事曆綠點（12/5 不亮、12/6 亮）、本週聚會日、點名日期、服事報名/排班日期清單、
  課堂紀錄/教案日期、詩歌「下次上課」、首頁提醒。
- 截止時間依實際聚會日重算：12/6 聚會 → 出席填寫 **12/5（週六）23:59** 截止；課後紀錄 12/8 截止。
- 之後遇到類似活動，在 `GATHERING_OVERRIDES` 加一筆即可：**不限週末**（如週六 → 下週二國定假日），可往前或往後挪、可超過一週、可同時多筆。
  平日聚會的截止一樣是前一天 23:59（週二聚會 → 週一 23:59）。
- 修正（11/10 複查）：往後挪時，「原定日已過、新日期未到」那幾天的「上一次聚會」原本會算不出來，已改為依挪動幅度自動放寬搜尋範圍，並補測試。
