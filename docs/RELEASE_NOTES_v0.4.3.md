# v0.4.3 更動內容（2026-09-30）

組長反饋兩項，純前端（CSS＋一個圖示名稱），`0.4.2` → `0.4.3`，無 migration。

## 1｜底部分頁：看得出現在在哪一頁

- 「點名」原本用實心的 `checked` 圖示，夾在五個線框圖示中間像一顆黑點，反而最難辨認 → 改成線框的 `passed`（圓圈打勾），六個圖示同一套風格
- 使用中的分頁，圖示後面鋪一塊**淡紫圓角底色**、文字加粗（比照常見 App 的做法）；光靠圖示變色組長反饋看不出來
- 分頁列高度 58 → 62px，給底色留空間；藥丸左右 12px，320px 寬的手機六格也放得下

## 2｜出席月曆：選到的那一格看得出報名了沒

原本選到的聚會日整格填成紫色，下方代表每個孩子狀態的圓點被改成白色／淡色——家長看不出到底報名成功沒有。

改成**只把日期數字填成圓形徽章**，整格維持淡紫底，圓點保持原色（綠＝出席、黃＝請假、灰＝未定/未填）。
本週的外框標示不變。數字框固定 26px 圓形，選取前後圓點不會跳位。

## 驗證

這一版**沒有跑測試帳號實機走一輪**：開發容器換新後 `.env.local`（Supabase 金鑰）不在了，
改以靜態頁面載入實際的 Vant 樣式與同一組 class 量測——使用中分頁底色 `#dad0ec`、分頁列 62px 文字不貼邊、
`passed` 字型有載到；選中格底色淡紫、數字徽章紫底白字、圓點色與未選中格完全相同。
`npm test` 260 項全綠、`npm run build` 通過。**請組長合併前在 Vercel 預覽用手機看一眼。**

## 手冊

不需更新：操作方式與圖例文字都沒變，只有視覺。圖文說明書維持 v0.4.0。
