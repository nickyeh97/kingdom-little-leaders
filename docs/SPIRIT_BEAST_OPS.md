# 小領袖靈獸：平台端要做的事（一頁看完）

> 2026-10-30 整理｜平台 v0.7.0｜遊戲 repo：`nickyeh97/kingdom-spirits`
> 原則：**體諒服事同工的辛勞——老師不增加任何工作。**

## 一句話

**老師照舊在紙本服事卡簽名；家長看到簽名後，陪孩子在遊戲裡按「＋1 服事」。** 其他都由系統自動算。

## 每個人要做什麼

| 誰 | 要做的事 | 多久一次 |
| --- | --- | --- |
| **老師** | 在孩子的紙本服事卡上簽名（**跟現在一樣**）。平台上**不用做任何事** | 孩子服事那天 |
| **家長** | 看到簽名 → 「我的 → 小領袖靈獸」→「去看靈獸 ▶」→「＋1 服事」，約 1 分鐘。<br>同一頁可以寫給孩子的話、刪掉記錯的紀錄 | 孩子服事後 |
| **同工** | 上線前做一次下面的「三步」；之後只有平常就在做的「兒童服事項目」維護 | 一次 |

## 不用做的事（原規格的流程，已取消）

規格書原本寫的「**報名 → 受訓中 → 已核定 → 服事完成**」四段狀態，要老師逐一更新每個孩子的狀態，**不做**。
這四段其實平台上已經有了，不必再多一套：

| 原本的狀態 | 現在由誰代表 | 老師要多做嗎 |
| --- | --- | --- |
| 報名 | 家長在「服事」頁的兒童服事報名（既有） | 不用 |
| 受訓中／已核定 | 名單頁的「逐項授權」（既有，該班老師或同工開通） | 不用 |
| 排班 | 同工發布的兒童服事表（既有） | 不用 |
| 服事完成 | 老師**紙本簽名**＋家長在遊戲登錄 | 不用（簽名本來就在做） |

另外也**不做**：老師在平台登錄服事履歷、老師審核家長的登錄、老師的服事卡檢視頁。
（資料庫仍保留「該班老師唯讀」的權限，萬一需要核對時同工可以查；但不放進老師的畫面，免得多一件要看的事。）

## 同工：上線前一次性三步（**照順序**）

1. **建資料表**：Supabase → SQL Editor → 貼上 `supabase/migrations/2026-10-02_service_card.sql` 全文 → Run。
   只新增兩張表（服事紀錄、靈獸設定）和權限規則，**不動既有資料**；重跑也沒關係。
   跑完貼這段確認，應看到 2 張表（`rowsecurity` 都是 `true`）、5 條規則：

   ```sql
   select tablename, rowsecurity from pg_tables
    where tablename in ('service_card_entries', 'beast_profiles');
   select tablename, policyname, cmd from pg_policies
    where tablename in ('service_card_entries', 'beast_profiles') order by 1, 2;
   ```

2. **部署遊戲**：遊戲 repo 合併進 `main` 後由 CI 部署到 Vercel（第一次的設定見遊戲 repo `docs/DEVELOPMENT.md`「部署」），記下遊戲網址。
3. **打開入口**：平台的 Vercel → Settings → Environment Variables 新增
   `VITE_SPIRIT_GAME_URL` ＝ 遊戲網址 → Redeploy。家長的「我的」就會出現「小領袖靈獸」。

> **一定要先做第 1 步再做第 3 步**：還沒建表就打開入口，家長點進去會看到錯誤訊息。
> 沒做第 3 步之前，家長完全看不到這個功能（可以安心先合併平台版本）。

## 驗收（同工用測試家長帳號跑一輪，約 5 分鐘）

測試帳號要：已審核、有家長標籤、綁定一位**兒童班**的孩子（測試資料一律用假名）。

1. 「我的 → 小領袖靈獸」→ 看到服事卡（每項 1 等）、「去看靈獸 ▶」
2. 去看靈獸 → 選一隻靈獸和顏色 → 回到平台，「寫給孩子的話」變成可以寫 → 寫一句、存好
3. 再去看靈獸 →「＋1 服事」→ 勾「我是家長」→ 選項目 → 選果子 → 儲存 → 星星慶祝，對話框出現剛剛寫的那句話
4. 回到平台：服事紀錄多一筆（日期、項目、果子），那個項目變 2 等；按「刪除」可以刪掉

「別的家長看不到這位孩子」的權限在資料庫層，已用本機資料庫跑過 33 項權限測試，不必再手動驗。

## 常見問題

- **孩子在幼童班／幼幼班？** 目前只開放兒童班（幼幼班沒有服事項目；幼童班 2026-10-03 裁決暫不開放）。
- **記錯了？** 家長在服事卡頁刪掉自己登錄的那筆，再到遊戲重新登錄。兩位家長都能登錄，但只能刪自己登錄的。
- **服事項目改名或停用？** 舊紀錄照樣算，顯示在原本的名稱下（標「已停用」）。
- **孩子好久沒服事？** 靈獸不會變弱、不會難過、也不會提醒——它一直在，等孩子下次回來（守則：不做留存壓力）。
- **遊戲顯示「登入已逾時」？** 從平台進遊戲的通行證約 1 小時有效；按遊戲裡的「回到牧區平台」，再點一次「小領袖靈獸」就好。
