# 兒童主日學整合平台（APP / Web APP）需求規格書

> 來源：2026-07 上傳之計畫案 PDF，內容整理如下，作為本計畫的需求基準（Requirement Baseline）。

## 專案背景與目標

為簡化兒主行政流程並建立「神國小領袖」文化，希望透過單一整合平台，處理預先出席統計、現場簽到、備課教材/影音/問題討論、服事履歷、敬拜歌單佈達與家長雙向通知。

## 使用者規模與硬體情境

- **使用者規模**：全教會兒童/幼童/幼幼孩子共 47 位、家長約 26 位、老師約 20 位。
- **主要裝置**：95% 以上使用者（家長、現場老師）皆以手機（iOS / Android 瀏覽器）操作。

## 核心功能需求（按模組拆解）

### 1. 出席預計統計與現場簽到（Attendance & Check-in）

- **家長預先統計（代替預約表單）**：
  - 每週固定時間（例如：週三前）開放家長在系統上勾選孩子「本週是否出席」。
  - 自動統計當週預計出席人數，方便行政窗口預備教材與物資。
- **老師現場簽到（代替簽到表單）**：
  - 主日現場由老師/窗口點選名單進行實到簽到。

### 2. 老師備課與教學資源區（Teacher's Hub & Media Center）

- **每週教材與影音（老師專用）**：
  - 後台可上傳/嵌入當週教學影音（如 GOOD TV《天國英雄榜》YouTube 連結或內建播放器）。
  - 附帶「課堂討論問題」與「帶領提示」文字區，方便老師用手機隨時隨地備課。
- **舞蹈動作教學影片庫**：存放簡化後的 2-3 個舞蹈動作示範短片，供帶敬拜老師提前觀看預備。
- **敬拜歌單發布**：後台可上傳 4 首歌曲（歌詞、音檔或 YouTube 純歌詞版連結）。
- **家長每週預習（家長端）**：每週主日結束後，家長端可看到下週敬拜歌曲與影片連結。

### 3. 服事經歷卡（Service History System）

- **服事履歷紀錄**：
  - 紀錄兒童服事細節（例如：2026/08/15 擔任 收奉獻組長 / 敬拜帶領）。
  - 狀態追蹤：受訓中、已通過核定、服事完成。
- **家長端視角**：家長可在系統內看到孩子的「小領袖服事履歷」。

### 4. 家長戰友連結與公告佈告欄（Parent Communication）

- **資訊佈達**：發布每週聚會公告、下週預告、課堂公約宣導。
- **雙向互動機制**：家長可針對公告進行回覆或簽到。

### 5. 權限管理機制

| 角色 | 權限 |
| --- | --- |
| 管理者（核心同工） | 全權存取、發布教材/歌單、維護名單、審核服事資格 |
| 老師端 | 現場簽到點名、檢視每週備課教材（影音+討論問題）、觀看動作教學影片、登錄服事履歷 |
| 家長端 | 填寫預先出席、預習歌單、查看孩子服事卡與接收公告 |

## 給工程師的開發階段建議（Roadmap）

1. **建議型態**：優先採用 **Web APP（RWD 響應式網頁）或 PWA**，免去 App Store / Google Play 上架審核流程，手機瀏覽器開啟加到主畫面即可使用。
2. **開發優先順序（MVP 最小可行性產品）**：
   - **Phase 1（急用/取代表單）**：預先出席統計、現場簽到點名、敬拜歌單/影片發布、家長佈告欄。
   - **Phase 2（文化深化）**：電子服事經歷卡、雙向互動。

## 跨班別擴充（幼童/幼幼班預留）

- **家長端「切換 / 多孩子綁定」介面（UI/UX）**：一位家長（26 位家長之一）可能同時有大娃（兒童班）與二娃（幼幼班），介面上需支援切換查看，或在勾選出席時可一次勾選多個孩子。

## 未來擴充預留（Future Roadmap）

1. **LINE 機器人/通知串接**：預先出席提醒與歌單自動推播。
2. **家庭延伸祭壇（家長端）**：提供主日討論題回饋與打卡。
3. **關懷警訊機制**：連續缺席自動標示，協助窗口 follow-up。
4. **資料庫預留**：建立 User 資料表時，建議預留生日、大孩子階級（培訓中/正式領袖）與家庭關聯 ID。
